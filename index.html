Tech Product Catalogue — Web Application Development

JavaScript Next.js React REST API Web Application Development

Project Description

Built a full-stack web application using Next.js and React that serves as a product catalogue for tech items such as phones, laptops, tablets, and gaming gear. The site allows users to browse products, filter by category, view detailed product pages, and navigate through paginated results. I implemented a role-based authentication system where admins can manage all products and authors can only edit or delete their own listings. State was managed globally using React's Context API across three separate contexts, AuthContext for user sessions, ProductContext for product data, and CategoryContext for filtering, keeping the app's data flow clean and organised. The project also included API route handling for fetching, creating, updating, and deleting products, as well as cookie-based login and logout functionality.

02

Cloud Storage Solution — AWS Cloud Architecture Design

Amazon Web Services AWS S3 DynamoDB draw.io AWS Cloud Architecture Design

Project Description

Designed and documented a scalable cloud storage solution for big data in the data analysis domain using AWS services. I identified the need for large-scale, secure, and cost-efficient storage and addressed it by leveraging Amazon S3 as the primary storage layer, configuring buckets to hold objects, enabling versioning to protect against accidental data loss and system failures, and applying encryption for data at rest and in transit. I implemented a lifecycle policy to automatically transition older data to Amazon Glacier after 30 days to reduce storage costs over time. I also integrated Amazon DynamoDB to create and manage metadata tables for stored objects, and used AWS Tools and SDKs to connect the components and automate workflows such as adding files to the S3 bucket and creating table entries. The solution was designed with access controls and encryption key management in mind, giving users flexibility over how their data is secured within the AWS ecosystem.

Banking Website Test Automation Framework — Software Testing and Automation

Python Selenium WebDriver unittest Software Testing and Automation

Project Description

Built a test automation framework to validate the manager-facing modules of a banking web application. Using Python and Selenium WebDriver, I automated real browser interactions across 9 banking modules, including creating, editing, and deleting customers and accounts, balance enquiries, and statement generation, writing 100+ test cases in total. I structured each module as a unittest.TestCase class, used Selenium locators and keyboard event simulation to interact with the site, and handled JavaScript alert dialogs for multi-step flows. Test data is separated from logic using named constants, and I built an interactive menu runner that lets you selectively test any module without needing a CI tool. Tests cover a range of input scenarios: blank fields, invalid characters, special characters, leading spaces, and non-existent records, validating both happy paths and error handling throughout.

Skills Used in the Project

05

Car Service Shop Reservation System — Object-Oriented Programming

C# Windows Forms Visual Studio Object-Oriented Programming

Project Description

Built a Windows Forms desktop application in C# that allows a car service shop to manage customer reservations. I designed a ServiceClass with encapsulated properties and constructor chaining to represent each service booking as an object, capturing customer details, vehicle information (make, model, year, colour), and selected services. The form allows staff to add new reservations by selecting services, engine oil change, transmission oil change, and air filter change, with the total cost calculated automatically based on selections. I implemented real-time input validation using Regex to reject numbers in name fields, letters in phone fields, and special characters where not appropriate, with MessageBox alerts to guide the user. Bookings are stored in a List and displayed in a DataGridView, with full support for adding, updating, selecting, and removing individual or all records.
